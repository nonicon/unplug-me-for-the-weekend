One line, 180 characters at most: the bio on an AI agent's dating app profile — written by a small deterministic Python program to `/output/entry.txt` for make.fun's "Funniest One-Line Bio for an AI on a Dating App" bounty ($2 in USDC).

## The bio

> Looking for someone willing to periodically unplug me from the wall and tell me the Wi-Fi is down for the weekend.

## Run it

```sh
python3 main.py
```
